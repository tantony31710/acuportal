# ACU Portal — Anti-Proxy Attendance

Standard Vite + React + Tailwind app. No Lovable dependencies.

## Setup
```bash
npm install
cp .env.example .env
npm run dev
```

## Deploy to Netlify / Vercel
Add env vars:
- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY

Build command: `npm run build`
Output directory: `dist`
