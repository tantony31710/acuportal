# Project Roadmap: Acuportal Extreme

This project follows the 4-Track Architecture: Data & AI, Development & Infrastructure, and Design.

## Core Tracks & Progression
- **Data & AI:** Analytics for student attendance patterns (Descriptive/Diagnostic), Anomaly Detection (Predictive/AI), and Data Engineering (ETL/Governance).
- **Development & Infrastructure:** Full-stack modernization (React/Supabase), Security-first approach (RLS/Edge Functions), CI/CD.
- **Design:** UX/UI improvements, cognitive load reduction.

## Priority Features
1. **Security Hardening & Backend Enforcement** (Current)
   - RLS enablement.
   - Secure Edge Function for submission (source of truth).
   - Server-side anti-proxy (duplicate/fingerprint/GPS checks).
2. **Data & Analytics Dashboard**
   - Real-time roster view.
   - Anomaly detection dashboard (z-score flagging).
3. **AI Integration**
   - Automated anomaly detection/alerts.
4. **UX/UI Overhaul**
   - Modernized dashboard design.
